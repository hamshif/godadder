
Setup Instructions
=
1. create a pyenv and activate it: 
   `pyenv virtualenv 3.11 godadder`
   `pyenv activate godadder`
2. run package py from the pyenv:
   `./package_py.sh`
3. run from anywhere
   `riff_names.py` 
4. If you want to see the names already gathered run from anywhere
   `show_domains.py`
